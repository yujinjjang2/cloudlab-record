아래 OneDrive 경로는 원본 보관소다. 이 저장소로 이동·삭제·일괄 복사하지 않는다.

| 원본 | 규모 | 이관 방향 |
| --- | ---: | --- |
| `Desktop\\실습 관련` | 12개 | SQL·DB 학습 내용을 일반화한 Markdown으로 이관 |
| `Desktop\\업무 관련` | 약 29,678개 | 주제별 기록만 선별 이관, 소스·산출물·원문은 제외 |
| `Desktop\\-` | 49개 | 참고자료만 검토, 인사·세무·연락망·휴가 자료는 제외 |

## 1차 이관 완료

- SQL 기본 DML 구조
- PL/SQL 블록 및 채번 시 고려사항
- SQL 조인·집계·검증 체크리스트
- 화면 기능 구현 흐름

## 다음 선별 우선순위

1. `업무 관련/공부`: 관리자·메뉴·코드 관리 절차를 고객·운영 식별값 없이 일반화한다.
2. `업무 관련/GIT`, `AI 관련`, `Vue 관련`: 계정·사내 저장소 URL·환경 경로를 제거한 학습 노트로 바꾼다.
3. `업무 관련/유지보수`, `레드마인 관련`, `권한별 메뉴추가`: 고객명·사용자·운영 데이터 없이 문제·처리·검증 항목만 기록한다.
4. `업무 관련/리포트`, `모바일 관련`, `화면설계 관련`, `테이블 관련`, `쿼리 관련`: 기능·플랫폼 기준으로 재분류한다.

## 제외 또는 별도 검토

- 연락망, 인사·세무·휴가·총무, 메일·회의·메신저 원문
- DB 터널링, 서버·보안·배포 설정, 라이선스 갱신 자료
- 고객 제공 파일과 첨부파일, 운영 로그, 원본 SQL·ERD·소스·빌드 산출물
