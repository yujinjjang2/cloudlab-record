# 시스템 메뉴 등록과 그룹별 메뉴 배정

- 작성일: 2026-09-10
- 분류: 시스템관리(관리자) · 메뉴관리 학습
- 상태: 원본 작업 메모를 공개 가능한 범위로 정리

## 원본 참고

회사명, 실제 사용자·그룹·조직 식별값, 운영 화면 주소 및 화면 캡처는 이 저장소에 적지 않는다. 세부 화면과 등록값이 필요하면 개인 보관 원본의 `업무 관련/공부/1. 시스템관리(관리자)/3. 메뉴관리/` 아래 `시스템메뉴 등록`, `회사별메뉴 등록`, `그룹별메뉴 등록`, `사용자별메뉴 등록` 메모를 확인한다.

## 시스템 메뉴 등록

업무 화면에서는 `시스템관리(관리자) > 메뉴관리 > 시스템메뉴등록` 순서로 들어간다.

- **시스템 등록**: 여기에서 등록한 시스템(폴더)이 시스템 메뉴 등록 화면에 읽기 전용으로 보인다.
- **1레벨 메뉴**: 최상위 시스템 폴더 바로 아래에 둘 메뉴를 등록한다.
- **2레벨 메뉴**: 1레벨 메뉴 아래에 프로그램을 연결한다. 프로그램을 추가하려면 먼저 `메뉴관리 > 프로그램등록`에서 프로그램 등록이 끝나 있어야 한다.

즉, 시스템 등록 → 프로그램 등록 → 시스템 메뉴 등록 순서가 맞는지 먼저 확인한다. 메뉴의 상위·하위 관계와 프로그램 연결 여부를 함께 점검한다.

## 회사·그룹·사용자별 메뉴 배정

- 회사별 메뉴 등록에서 회사에 사용할 프로그램을 먼저 추가한다.
- 그룹별 메뉴 등록의 조회 조건에는 사용자 그룹 등록에서 만든 그룹이 보인다.
- 그룹마다 다른 메뉴를 줄 수 있다. 그룹별 메뉴를 배정하려면 회사별 메뉴 등록에 프로그램이 먼저 추가되어 있어야 한다.
- 관리자 그룹에는 회사별 메뉴 등록에서 추가한 프로그램이 자동으로 들어가는 동작이 있다. 그 외 그룹은 필요한 메뉴를 별도로 추가한다.
- 사용자별 메뉴 등록이 필요한 경우에는 그룹 권한과 개별 사용자 권한이 화면 표시 및 실제 실행 권한에 어떻게 반영되는지 함께 확인한다.

## 등록·변경 확인 목록

- 시스템 등록값이 시스템 메뉴 등록 화면에서 읽기 전용으로 보이는가?
- 1레벨 메뉴는 시스템 아래에, 2레벨 메뉴와 프로그램은 올바른 상위 메뉴 아래에 연결됐는가?
- 프로그램 등록과 회사별 메뉴 등록이 선행되지 않은 상태에서 메뉴 배정을 시도하지 않았는가?
- 조회한 그룹이 사용자 그룹 등록의 대상과 일치하는가?
- 관리자 그룹의 자동 배정과 다른 그룹의 수동 배정이 의도대로 표시되는가?
- 메뉴 변경 뒤 대상 계정으로 로그인해 메뉴 표시와 직접 접근·실행 권한을 모두 확인했는가?
