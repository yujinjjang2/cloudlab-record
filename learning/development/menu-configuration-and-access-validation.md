# 메뉴 구성과 접근 표시 검증

- 작성일: 2026-09-10
- 분류: 관리자 기능 학습
- 상태: 일반화 완료

## 구성 순서

1. 메뉴가 속할 시스템 또는 기능 영역을 먼저 등록한다.
2. 실행 대상 기능을 등록하고, 메뉴와 기능의 연결 가능 여부를 확인한다.
3. 최상위 메뉴와 하위 메뉴를 계층으로 구성한다. 하위 메뉴에는 연결할 기능을 지정한다.
4. 조직 단위에서 사용할 수 있는 메뉴와 기능을 배정한다.
5. 역할 또는 사용자 그룹별로 표시할 메뉴를 선택한다. 공통 역할의 기본 권한과 개별 역할의 추가 권한은 구분한다.

## 입력과 변경 검증

- 상위 메뉴, 메뉴 이름, 표시 순서, 연결 기능 등 필수 입력값을 저장 전에 검증한다.
- 메뉴의 깊이 제한과 상위 메뉴가 존재하는지를 검사해 순환 구조나 고아 메뉴를 막는다.
- 연결되지 않은 기능, 사용 중인 메뉴의 삭제, 중복 표시 순서는 명확한 오류로 안내한다.
- 메뉴를 변경한 뒤에는 대상 역할의 화면에서 표시 여부와 실행 가능 여부를 함께 확인한다.

## 접근 제어 확인 목록

- 조직 단위의 메뉴 배정이 역할별 메뉴 선택의 선행 조건인지 확인한다.
- 기본 역할과 일반 역할에 같은 메뉴가 의도대로 다르게 보이는지 확인한다.
- 메뉴 숨김만으로 권한을 판단하지 않고, 직접 경로 접근과 기능 호출도 거부되는지 검증한다.
- 권한 또는 메뉴 변경에는 변경 주체, 시각, 이전값과 이후값을 남긴다.
- 설정 변경 후에는 캐시 또는 세션 갱신이 필요한지 확인하고, 최소 두 역할로 회귀 검증한다.
