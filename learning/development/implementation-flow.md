# 화면 기능 구현 흐름

1. 화면 설계서와 ERD를 읽어 입력·조회·저장 범위를 정한다.
2. 조회와 저장에 필요한 데이터·조건을 정리한다.
3. 화면 데이터 모델과 목록 바인딩을 구성한다.
4. 화면과 데이터 모델을 연결한다.
5. 공통 규칙을 먼저 적용하고, 조회·저장 등 이벤트와 요청 객체를 구현한다.
6. 서버의 Controller → Service → ServiceImpl → Mapper 흐름을 구성한다.
7. 화면의 조회 조건과 서버 쿼리를 연결한 뒤, 정상·빈 결과·오류·권한 부족 경로를 검증한다.

## 구현 전 확인

- 설계서와 ERD의 용어가 일치하는지
- 필수 입력값과 저장 가능 조건이 정의되었는지
- 조회 조건이 쿼리 조건과 정확히 대응하는지
- 저장 후 화면 갱신과 오류 안내 방식이 준비되었는지
