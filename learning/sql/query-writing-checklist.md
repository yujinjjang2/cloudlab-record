# SQL 작성 체크리스트

## 조인

- 기준이 되는 메인 테이블을 먼저 정한다.
- 메인 행은 유지하면서 상대 테이블의 값이 없을 수 있으면 Oracle 외부 조인 `(+)` 적용 여부를 검토한다.
- `From` 절에는 업무상 중요한 테이블부터 배치해 읽기 쉽게 만든다.
- 조인 조건과 검색 조건을 구분해 누락·중복을 점검한다.

## 집계와 표시

- 여러 행을 하나의 표시값으로 묶어야 할 때 `Listagg` 등 집계 함수를 검토한다.
- 집계 기준과 정렬 기준을 명시해 결과의 순서가 우연에 의존하지 않게 한다.

## 검증

- 실행 전 바인딩 값, 대상 행 수, 중복 가능성을 확인한다.
- 변경 SQL은 동일 조건의 조회 SQL과 함께 준비한다.
- 성능이 중요한 쿼리는 실행 계획과 인덱스 사용 여부를 확인한다.
