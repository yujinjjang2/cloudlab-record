# PL/SQL 블록과 문서번호 채번 개념

PL/SQL 블록은 선언부, 실행부, 예외 처리부로 구성한다. 선언부와 예외 처리부는 선택 사항이며 실행부는 필수다.

```text
Declare
    -- 변수·상수 선언
Begin
    -- 조회·저장·분기 처리
Exception
    -- 예외 처리
End;
```

## 채번 시 고려할 점

- 접두사와 기준 연도·일자 등 채번 규칙을 먼저 확정한다.
- 현재 최대값이 없을 때의 최초 번호를 처리한다.
- 숫자 부분을 추출해 증가시키고, 필요한 자릿수만큼 0을 채운다.
- 동시 저장 상황에서 중복 번호가 생기지 않도록 시퀀스·잠금·고유 제약 등 적절한 방식을 검토한다.
- 필수 입력값이 없으면 의미가 분명한 예외로 처리한다.

원본 실습 쿼리의 업무 테이블명과 실제 식별값은 이 문서에 포함하지 않는다.
