# 통합 결과 집합의 페이지 나누기

- 작성일: 2026-09-17
- 분류: SQL 학습
- 상태: 일반화 완료

## 다루는 문제

서로 다른 두 목록을 `Union All`로 합쳐 페이지를 나누는 조회에서, **각 목록에 먼저 순번을 매긴 뒤 합치면 순번이 중복된다.** 예를 들어 첫 목록의 1~10번 행과 둘째 목록의 1~5번 행이 합쳐지면, 화면에서 1~5번을 요청했을 때 각각의 목록에서 1~5번이 선택되어 총 10건이 반환될 수 있다.

이 노트는 이 오류를 고치기 위해 순번을 부여하는 위치를 옮기는 방법을 정리한다.

## 원인과 수정 방향

문제 쿼리의 구조는 아래와 같다. 각 목록이 독립적으로 1번부터 시작하므로, 합친 결과에서는 `SORT_NO`가 고유하지 않다.

```sql
-- 잘못된 구조: 각 원본에서 순번을 계산한 뒤 결합
Select
    Row_Number() Over(Order By a.DOCUMENT_ID) SORT_NO  -- 원본별 순번
From
    SOURCE_A_DOCUMENT a
Union All
Select
    Row_Number() Over(Order By b.DOCUMENT_ID) SORT_NO  -- 원본별 순번
From
    SOURCE_B_DOCUMENT b
```

수정할 때는 두 목록을 먼저 하나의 중간 결과로 만들고, 그 결과에만 순번을 부여한다. 그러면 두 목록 전체에서 `SORT_NO`가 1, 2, 3처럼 한 번씩만 생긴다.

```sql
-- 수정 구조: 결합된 결과에 전역 순번을 한 번만 계산
Select
    Row_Number() Over(Order By a.DOCUMENT_ID) SORT_NO  -- 전체 결과 순번
From
    (
        Select
            a.DOCUMENT_ID  -- 첫 번째 목록의 정렬 키
        From
            SOURCE_A_DOCUMENT a
        Union All
        Select
            b.DOCUMENT_ID  -- 두 번째 목록의 정렬 키
        From
            SOURCE_B_DOCUMENT b
    ) a
```

실제 화면 조회에서는 이 전역 순번을 바깥 조건에서 페이지 시작값과 끝값 사이로 제한한다. 전체 건수도 같은 전역 순번 단계에서 계산해야 화면 건수와 페이지 수가 일치한다.

```sql
-- 페이지 구간은 전역 순번에만 적용
Select
    a.SORT_NO  -- 전체 결과 순번
From
    PAGE_TARGET a
Where 1 = 1
And a.SORT_NO Between #{PAGE_START} And #{PAGE_END}
```

## 핵심 원칙

- 각 원본에 따로 순번을 매기지 말고, 원본 결과를 모두 결합한 뒤 최종 결과 집합에 한 번만 순번을 부여한다.
- 정렬 기준은 결과가 다시 실행되어도 재현될 수 있도록 안정적인 키와 필요한 보조 키를 함께 사용한다.
- 페이지 범위는 요청한 페이지 번호와 크기에서 계산하되, 시작·끝 경계가 한 행도 겹치지 않도록 검토한다.
- 전체 건수가 필요하면 페이지 필터를 적용하기 전의 통합 결과를 기준으로 계산한다.

## 적용 순서

1. 각 원본에서 화면에 필요한 열과 공통 의미를 먼저 맞춘다.
2. 원본 결과를 하나의 중간 결과로 결합한다.
3. 결합 전에 계산된 원본별 순번이 있으면 제거한다.
4. 중간 결과에 결정적인 정렬 기준으로 전역 순번을 부여한다.
5. 전역 순번을 사용해 요청한 구간만 선택하고, 필요하면 같은 단계에서 전체 건수를 제공한다.
6. 빈 페이지, 마지막 페이지, 원본별 건수 차이가 큰 경우를 포함해 결과를 검증한다.

## 검증 체크리스트

- 첫 목록이 10건, 둘째 목록이 5건인 예시에서 첫 페이지 1~5번이 정확히 5건만 반환되는지 확인한다.
- 결합 결과의 순번이 1~15처럼 중복 없이 연속되는지 확인한다.
- 원본별 순번이 아니라 전체 결과의 연속된 순번인지 확인한다.
- 같은 정렬 조건으로 재조회했을 때 행의 위치가 바뀌지 않는지 확인한다.
- 첫 페이지·중간 페이지·마지막 페이지의 건수와 경계 행을 비교한다.
- 전체 건수와 모든 페이지의 합계가 일치하는지 확인한다.
- 중복 키·동률 정렬값·빈 원본이 있을 때의 동작을 시험한다.
- 대량 데이터의 실행 계획과 응답 시간은 승인된 비운영 환경에서만 점검한다.

## 반입 범위

이 노트는 특정 조회에서 발생한 순번 중복과 페이지 건수 오류를, 가상의 목록·열 이름으로 재구성했다. 실제 테이블·열 이름, 업무 데이터, 운영 쿼리, 접속 정보는 포함하지 않는다.
