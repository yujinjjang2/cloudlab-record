# 대시보드 개인화와 반응형 데이터 흐름

- 작성일: 2026-09-10
- 분류: Vue 학습
- 상태: 일반화 완료

## 개인화 설계

- 사용자가 대시보드 구성과 위젯 표시 순서를 조정할 수 있게 하되, 공통으로 유지해야 하는 화면은 편집 범위를 제한한다.
- 화면별 설정은 독립적으로 관리하고, 사용자가 명시적으로 저장했을 때 다음 접속에도 같은 구성이 복원되도록 한다.
- 위젯의 표시 대상과 표시 조건을 데이터 모델로 분리한다. 공용 위젯과 특정 범위에만 보이는 위젯을 같은 기준으로 설명할 수 있어야 한다.
- 정렬 방향, 표시 여부, 이름 변경 등 사용자 옵션은 기본값과 함께 정의한다.

## 위젯 상태와 데이터 갱신

1. 위젯의 입력값, 로딩 상태, 오류 상태, 표시 데이터를 분리한다.
2. 입력값이 바뀌면 필요한 데이터만 다시 요청하고, 요청 중에는 로딩 상태를 사용자에게 보여 준다.
3. 같은 데이터를 보여 주는 위젯은 공통 데이터 접근 계층을 사용해 중복 요청과 상태 불일치를 줄인다.
4. 3차원·외부 시각화처럼 초기화 비용이 큰 위젯은 준비 완료 여부를 별도 상태로 관리한다.
5. 데이터가 없거나 권한이 부족하거나 요청이 실패한 경우를 각각 검증한다.

## Vue 구현 시 확인

- 컴포넌트 간 공통 상태와 의존성은 명시적인 주입 또는 상태 관리 방식으로 전달한다.
- 화면 데이터 요청은 공통 API 모듈로 감싸고, 요청·성공·실패 처리를 일관되게 한다.
- 사용자 설정에는 식별 가능한 값 대신 일반화된 설정 키를 사용하고, 인증 정보나 비밀값은 화면 설정에 저장하지 않는다.
- 위젯 추가·순서 변경·이름 변경·저장 후 재접속을 시나리오로 검증한다.
