# Cloudlab Record

업무와 학습 과정에서 얻은 내용을, 다음 작업을 이어갈 수 있는 Markdown 기록으로 정리하는 저장소입니다. 원본 자료는 개인 OneDrive에 보존하고, 이 저장소에는 재사용 가능한 절차·판단 기준·학습 내용을 일반화해 남깁니다.

## 기록 원칙

- 원본 파일을 그대로 복사하지 않는다. 기록 목적에 맞게 Markdown으로 재작성한다.
- 고객명, 담당자, 연락처, 계정, 사업자등록번호, 운영 데이터 식별값을 기록하지 않는다.
- 비밀번호, API 키, DB 접속 정보, IP, 서버 경로, 터널링 설정, 인증서, 로그 원문은 기록하지 않는다.
- 사내 소스 코드, 고객 제공 파일, 회의·메일 원문은 업로드하지 않는다. 필요한 내용은 일반화된 학습 또는 절차 노트로 바꾼다.
- 한 문서는 한 주제를 다루며, 배경·처리 절차·검증 항목·주의사항을 명확히 적는다.

## 폴더 구조

```text
cloudlab-record/
├── work/                       # 일반화된 업무 기록
│   ├── 00-guides/              # 기록 원칙과 템플릿
│   ├── 10-features/            # 기능 단위 분석
│   ├── 20-platforms/           # WEB, API, 모바일, 리포트 공통 기록
│   ├── 30-external-services/   # 외부 연동·인증의 일반 원칙
│   ├── 40-client-maintenance/  # 고객사 유지보수 절차
│   └── 90-archive/             # 더 이상 갱신하지 않는 참고 기록
├── learning/                   # SQL, DB, Git, 프론트엔드 등 학습 노트
└── migration/                  # 원본 자료 선별·이관 현황
```

## 이관 방식

원본 OneDrive 폴더는 이동하거나 삭제하지 않는다. 파일별로 민감정보와 저작권·기밀성을 검토한 뒤, 공개 가능한 핵심만 이 저장소에 새 문서로 작성한다. 상세 기준은 [이관 인벤토리](migration/source-inventory.md)를 참고한다.
