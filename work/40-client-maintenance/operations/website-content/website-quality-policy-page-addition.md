# 홈페이지 카테고리·상세 페이지·첨부 자산 추가

- Redmine: #36849
- 작업일: 2026-08-28
- 상태: 해결

## 작업 요청

소개 메뉴의 기존 항목 사이에 신규 카테고리를 추가하고, 상세 페이지와 고객 전달 이미지를 함께 게시한다.

## 수정 대상

| 구분 | 상대 경로 | 작업 내용 |
| --- | --- | --- |
| 사이드 메뉴 | `View/Introduction/commonIntroductionMenu.jsp` | 신규 카테고리 추가 |
| 상세 페이지 | `View/Introduction/qualityCourse.jsp` | 신규 안내 페이지 추가 |
| 페이지 이동 | `Script/common.js` | 페이지 이동 경로 또는 함수 추가 |
| 이미지 | `Image/introduction/quality_course.jpg` | 전달 이미지 배치 |

## 작업 순서

1. 배포 서버와 웹 루트를 내부 운영 문서에서 확인한다.
2. 기존 메뉴 순서와 대상 페이지 존재 여부를 확인한다.
3. 사이드 메뉴, 상세 페이지, 공통 이동 로직, 정적 이미지를 순서대로 반영한다.
4. 메뉴 → 상세 페이지 → 이미지 표시를 운영 화면에서 확인한다.
5. 변경 항목과 검증 결과를 안내한다.

## 확인 항목

- 신규 메뉴의 명칭과 순서가 요청과 일치하는지
- 메뉴 클릭 시 상세 페이지로 이동하는지
- 본문과 이미지가 정상 표시되는지
- 기존 메뉴·페이지에 회귀 영향이 없는지
