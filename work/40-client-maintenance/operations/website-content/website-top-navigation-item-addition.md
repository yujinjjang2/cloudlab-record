# 홈페이지 상단 메뉴 하위 카테고리 추가

- Redmine: #36871
- 작업일: 2026-09-04
- 상태: 해결

## 작업 요청

홈페이지 상단 메뉴의 하위 카테고리로 신규 항목을 추가하고, 선택 시 지정된 안내 페이지로 이동하게 한다.

## 수정 대상

| 구분 | 상대 경로 | 작업 내용 |
| --- | --- | --- |
| 상단 공통 메뉴 | `View/Main/commonTop.jsp` | 상단 메뉴의 하위 카테고리 추가 |
| 페이지 이동 | 링크 또는 공통 이동 함수 | 대상 페이지 연결 |

## 작업 순서

1. 내부 운영 문서에서 대상 배포 환경을 확인한다.
2. 상단 공통 메뉴의 하위 구조를 확인한다.
3. 신규 메뉴와 대상 페이지 이동 연결을 추가한다.
4. 상단 메뉴 → 신규 항목 → 대상 페이지 이동을 확인한다.
5. 공통 헤더를 사용하는 주요 화면의 레이아웃을 확인한다.

## 확인 항목

- 상단 메뉴에 신규 항목이 정상 노출되는지
- 선택 시 올바른 페이지로 이동하는지
- 기존 메뉴의 순서·링크·스타일에 영향이 없는지
- 캐시를 비운 브라우저에서도 결과가 동일한지
