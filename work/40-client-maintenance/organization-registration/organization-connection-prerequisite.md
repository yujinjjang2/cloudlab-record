# 스마트업무관리 조합등록: 연결중 전환 오류 조치

- Redmine: #36870
- 작업일: 2026-09-04
- 상태: 해결

## 작업 요청

스마트업무관리의 **홈페이지관리 > 조합등록**에서 신규 조합을 등록한 후, 연결여부를 `연결안함`에서 `연결중`으로 변경하면 필수조건 미입력 오류가 발생한다.

## 원인

`연결중`으로 변경하려면 대상 조합의 **조합회사코드 설정**이 선행되어야 한다. 조합을 기존 회사와 연동할지, 신규 회사로 등록할지를 먼저 결정해야 한다.

## 처리 순서

1. 대상 조합을 기존 회사와 연동할 수 있는지 확인한다.
2. 기존 회사 연동이면 해당 회사를 기준으로 조합회사코드를 설정한다.
3. 신규 회사 등록이면 필요한 회사 식별 정보를 받아 회사를 등록한다.
4. 신규 회사 기준으로 조합회사코드를 설정한다.
5. **홈페이지관리 > 조합등록**에서 연결여부를 `연결중`으로 변경한다.
6. 저장 후 홈페이지 노출과 연결 상태를 확인한다.

## 확인 항목

- 기존 회사 연동 또는 신규 회사 등록 판단이 완료되었는지
- 조합회사코드가 설정되었는지
- 연결 상태 변경·저장 시 오류가 재발하지 않는지
- 홈페이지에서 조합이 정상 노출되는지
