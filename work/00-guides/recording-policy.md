# 기록 작성·반입 정책

## 반입 가능

- 일반화한 개발·운영 절차와 검증 체크리스트
- 공개 가능한 SQL·DB·Git·프론트엔드 학습 메모
- 고객사 식별 정보를 제거한 유지보수 사례
- 코드 전문이 아닌 설계 판단, 흐름, 실패 원인과 해결 기준

## 반입 금지

- 계정, 비밀번호, 토큰, 키, 인증서, 접속 URL, IP, 서버 경로
- 고객·직원 개인정보, 연락처, 인사·세무·휴가 자료
- 고객 제공 문서·이미지·첨부파일, 메일·회의 원문, 메신저 대화
- 사내 소스 전문, 운영 DB 덤프, 로그 원문, 빌드 산출물

```markdown
# 주제

- 상태:
- 분류:

## 배경

## 처리 또는 학습 내용

## 확인 항목

## 주의사항
```
